# מסלול אזרחות יא׳

אתר ללימוד החומר באזרחות לכיתה יא׳ (תשפ״ו), מחולק לשישה מפגשים.

- **מפגשים 1–6**: הגדרות בנוסח החוברת, עם הסבר קצר, דוגמה וטריק זכירה.
- **שינון**: כרטיסיות עם חזרה מרווחת, והשוואה מילה במילה מול ההגדרה.
- **כתיבה מדויקת**: כתיבת טקסט מהזיכרון ובדיקה אות באות, כולל פיסוק.
- **תרגול בגרות**: שאלות אירוע עם תשובה לדוגמה (ציין-הצג-צטט-הסבר).

ההתקדמות נשמרת בדפדפן (localStorage) ולא נשלחת לשום שרת.

## הפעלה
פותחים את `index.html` בדפדפן, או מפרסמים את התיקייה ב-GitHub Pages.

## קבצים
- `index.html` – האתר
- `data1.js` – החומר של מפגשים 1–3
- `data2.js` – החומר של מפגשים 4–6 ושאלות האירוע
