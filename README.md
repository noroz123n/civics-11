# מסלול אזרחות יא׳

אתר ללימוד החומר באזרחות לכיתה יא׳ (תשפ״ו), מחולק לשישה מפגשים.

- **מפגשים 1–6**: הגדרות בנוסח החוברת, עם הסבר קצר, דוגמה וטריק זכירה.
- **שינון**: כרטיסיות עם חזרה מרווחת, והשוואה מילה במילה מול ההגדרה.
- **כתיבה מדויקת**: כתיבת טקסט מהזיכרון ובדיקה אות באות, כולל פיסוק.
- **תרגול בגרות**: 152 שאלות מ-8 בחינות בגרות אמיתיות (2018–2026) שיש להן דגם תשובות רשמי של משרד החינוך, עם תשובה מלאה לפי הגדרות החוברת; קישורים לכל השאלונים במאגר; ושאלות אירוע לתרגול.

ההתקדמות נשמרת בדפדפן (localStorage) ולא נשלחת לשום שרת.

## הפעלה
פותחים את `index.html` בדפדפן, או מפרסמים את התיקייה ב-GitHub Pages.

## קבצים
- `index.html` – האתר
- `data1.js` – החומר של מפגשים 1–3
- `data2.js` – החומר של מפגשים 4–6 ושאלות האירוע לתרגול
- `exams/` – שאלות מבחינות הבגרות, התשובות לפי החוברת, ורשימת השאלונים במאגר

## זכויות יוצרים
שאלוני הבגרות ודגמי התשובות שייכים למשרד החינוך ("אין להעתיק או לפרסם אלא ברשות משרד החינוך"). לכן באתר הציבורי הקטעים והתשובות הרשמיות מוצגים כקישור לשאלון המקורי (`CIV_LINK_ONLY = true` ב-`index.html`).
